# Timeline de referencia — vídeo de launch (formato "holo")

Referencia: `ssstik.io_1793039673147.mp4` (launch de holo, "AI CMO"). 44,7 s, 30 fps, 16:9 (1024×576). Contenido real hasta ~42,5 s; después, negro.

## Reglas del formato

- **Fondo blanco/hueso casi siempre.** El color lo pone un único degradado de marca (naranja → magenta → azul) que aparece como relleno de letras, blobs borrosos, "cortina" de franjas verticales, esferas y barras. Nada más tiene color salvo los mockups y las fotos.
- **Texto = narrador.** No hay voz en off: música con pegada y el guion se cuenta con 1–3 palabras por pantalla, siempre centradas, sans geométrica negra (bold) o rellena con el degradado.
- **Cambio visual cada 0,5–1,5 s.** Ninguna imagen está quieta más de ~2 s salvo el bloque de "trabajo continuo" (24–36 s), que es deliberadamente más lento.
- **Kinetic type palabra a palabra**: las palabras entran en desenfoque/deformación, se asientan y la siguiente sustituye a la anterior en el mismo sitio.
- **Transiciones "match"**: el objeto de una escena se convierte en el de la siguiente (puntos → teléfono, input de dominio → lo lleva la mascota, toggle → collage, collage → pantalla de un monitor). Casi no hay cortes secos.
- **Lista con indicador (dot)**: lista vertical de features en gris; la activa en negro con un punto degradado delante, y a la derecha una tarjeta/mockup que cambia con cada ítem.
- **Mascota 3D** como personaje de marca (aparece una vez en acción y luego como icono inline dentro del texto).
- **Cierre**: claim → número que sube con gráfica → URL sola sobre blanco.

## Estructura abstracta (para reutilizar)

1. **Hook (0–7 s)** — "Tú tienes X" en 3–4 pantallas de texto + 1 plano de producto en mano.
2. **Giro (7–10 s)** — una palabra ("Ahora") + un visual abstracto de escala.
3. **Reveal (10–12 s)** — "Conoce" → logo. Silencio visual.
4. **Cómo empieza (12–15 s)** — el input/acción mínima para empezar + la mascota haciendo la acción.
5. **Features (15–21 s)** — lista de 4 con dot, ~1,5 s por ítem, mockup a la derecha.
6. **Payoff (21–37 s)** — toggle "en automático" → "día y noche" → producción continua → plano real.
7. **Claim + resultado (37–41 s)** — posicionamiento en 3 palabras + número que sube.
8. **CTA (41–43 s)** — URL.
