# Marca Diariamente

El símbolo es una persona dentro de la D, mirando el sol que sale: el diario entre sesiones, la mente y cada día.

## Archivos

| Archivo | Uso |
|---|---|
| `diariamente-horizontal-color.svg` | Logo principal |
| `diariamente-horizontal-color-negativo.svg` | Sobre fondos oscuros (tinta) |
| `diariamente-horizontal-negro.svg` | Una tinta |
| `diariamente-vertical-color.svg` | Formatos cuadrados o estrechos |
| `diariamente-simbolo-color.svg`, `-negro`, `-blanco` | Símbolo solo, desde 32 px |
| `diariamente-simbolo-pequeno-color.svg` | Símbolo por debajo de 32 px (hasta 16 px) |
| `diariamente-icono-app.svg`, `diariamente-icono-maskable.svg` | Iconos de app y PWA |
| `diariamente-favicon.svg` | Favicon |

Los PNG de la app (`app/favicon.ico`, `app/icon.png`, `public/icon-*.png`, `public/apple-touch-icon.png`, `public/logo.png`) se exportaron desde estos SVG.

## Color

| Nombre | HEX | Uso |
|---|---|---|
| Tinta | `#25282C` | Logo, texto y acciones (`--primary`) |
| Sol | `#F79A6B` | Único acento del logo |
| Sol degradado | `#FFC48A` → `#F58F63` | Solo en el icono de app |
| Crema | `#FCF8F2` | Fondos |
| Salvia | `#7E9686` | Secundario |
| Pizarra | `#5E8299` | Secundario |
| Arcilla | `#E3A792` | Secundario |

Sin morados ni lilas en ningún elemento de marca.

## Tipografía

Logotipo en Quicksand Bold convertido a trazados; solo la D en mayúscula. Interfaz en Quicksand (`public/fonts`).

## Reglas

- Espacio de respeto: como mínimo el ancho del trazo vertical de la D alrededor del logo.
- Tamaño mínimo: logo horizontal 120 px de ancho; símbolo 32 px (debajo, la versión pequeña).
- No deformar, girar, cambiar colores ni añadir sombras o brillos al logo.
